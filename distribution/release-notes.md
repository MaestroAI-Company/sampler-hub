## Sign in from the network

A device on the same network as the hub can now sign into an existing profile with its password alone, no pairing code needed. Opera lists the hub's profiles as soon as you tap **Link to** the hub, you pick yours and type its password.

A pairing code is still needed to create a new profile, and to pair from outside the network.

This only works while **Visible on the local network** is on in the hub settings. Turn it off and the hub only pairs with a code again. Wrong passwords count toward the same lockout as unlocking a profile.

## Privacy between profiles

- Members now only see their own profile. Admins still see every profile.
- CPU and memory use of the hub are only sent to admins.

## Profile cards

Each profile now keeps its Maestro butterfly on the hub, so every device shows a profile's card with that profile's butterfly instead of its own.

Opera needs its next update to sign in from the network. Older versions keep pairing with a code.
